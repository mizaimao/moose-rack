# Mega Drive rename plan

90 files whose name does not match their contents.

Identified by hashing each ROM and matching it in the No-Intro database.
Six were confirmed a second way, by reading the title stored inside the ROM.

RomM cannot rename a file, so each of these is: upload the same bytes under
the correct name, verify it arrived, then delete the old entry. The ROM data
is untouched -- only the label changes.
