# Lists

One-off snapshots, not documentation and not generated by anything in this
repo — nothing here regenerates if you delete it. They were made once, from a
server and a drive in the state they were in on the date at the top of each
file, and they are kept because each one is a decision waiting to be made
rather than a record of one already taken.

| File | What it is | Rows |
| --- | --- | --- |
| `audit-name-vs-content.tsv` | Files here whose name is not the game inside, and what the server calls those bytes | 190 |
| `audit-server-art-stranded.tsv` | Server artwork left under an old name on purpose: the picture is of the game the ROM was misnamed as | 162 |
| `audit-sync-applied.tsv` | What the 2026-08-28 sync did: every file renamed, fetched or parked | 1,794 |
| `worth-taking.tsv` | Games on the Super Game HDD the server does not have, rated 80+ | 3,556 |
| `arcade-proposed-names.tsv` | Names as the emulator reads them from the romset, with region | 1,613 |
| `wanted-by-consensus.tsv` | Per-platform want-lists from Time Extension and Wikipedia | 629 |
| `canon-wanted.tsv` | Wikipedia's cited canon, checked against the server | 369 |
| `arcade-label-mismatches.tsv` | Labels that differ from the emulator's name | — |
| `arcade-labels-alias.tsv` | Differences that are just a known alias | — |
| `arcade-labels-wrong.tsv` | Labels sharing no word with the emulator's — likely the wrong game | 66 |
| `arcade-core-fixes.tsv` | Games needing a core other than the default | — |
| `knulli-roms-folders.txt` | The card's ROM folders, as they were | — |
| `knulli-systems-unmapped.txt` | KNULLI systems with no mapping on our side | — |

The rating in `worth-taking.tsv` is the one already in that drive's own
`gamelist.xml`, not anybody's opinion.

If one of these has been acted on, delete it — a stale want-list read as
current is worse than no list.
