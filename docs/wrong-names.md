# Games whose name does not match their contents

126 files across 12 systems. Found by hashing every ROM and looking the
hash up in the No-Intro database (libretro-database, 2026-08-01).

Six of the Mega Drive entries were checked a second way, by reading the title
stored inside the ROM itself; the header agreed with the database every time.

A handful of these will be the same game under a different language's title
(Korean and French re-releases especially). The rest are genuinely wrong.
